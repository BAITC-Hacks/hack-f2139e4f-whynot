## Исправления frontend

1. Устаревавшие XP: `RoleContext` обновляет команду при навигации и возвращении во вкладку после проверки сессии. Профиль, sidebar и прогресс используют общий Team.
2. Несохранённые поля команды больше не заменяются фоновым обновлением XP. Четыре новых unit-теста проверяют слияние полей, включая намеренно очищенные значения.
3. Повтор после ошибки команды загружает сессию и команду в фоне, не размонтируя форму. Продолжение запроса защищено identity и generation.
4. Отменённый комментарий отказа очищается и не передаётся при принятии.

Переход между страницами проверен в браузере. Отдельное событие focus/visibilitychange и сохранность формы при сетевом retry проверены код-ревью и тестами логики слияния, но не отдельным автоматизированным React-тестом.

## Ограничения и задачи для backend

Область этих выводов — проверенный snapshot `72a6f218`. При подготовке push получены более новые `origin/backend` (`96f3cac`) и `origin/main` (`92efc54`); в них уже есть отдельные изменения участников команд, профилей и чата (`e72954c`). Они ещё не объединены с этой веткой frontend и не участвовали в описанном прогоне. Ограничения ниже нельзя переносить на новую ветку backend без повторной проверки.

- Общей команды из нескольких аккаунтов пока нет: регистрация студента создаёт отдельную Team с одним owner_id. Membership, приглашения и вступление отсутствуют в API. На фронтенде это невозможно добавить без нового контракта.
- Сервер разрешает повторный одинаковый отклик (проверено: 201, новый ID, pending). Уникальность этапа действует только внутри proposal_id. По коду backend два принятых дубля могут независимо начислить XP одной команде за ту же задачу; этот сценарий требует серверного ограничения, если опыт должен выдаваться один раз на пару task/team. Дубли не принимались специально для накрутки в проведённом сценарии.
- Голосовой API проверен синтетическим WAV длиной 1 секунда: ответ 503 AI_NOT_CONFIGURED. Для голосового ввода нужен ключ OpenAI в конфигурации backend.
- В локальном запуске используется AI_PROVIDER=stub. Реальная генерация AI, качество распознавания речи и SMTP-доставка не входят в подтверждённый результат этого прогона. Микрофон пользователя не включался.
- Почта локально настроена в MAIL_MODE=file. Проверка реальной доставки письма пользователю требует настроенного SMTP.
- На ширине 300 px появляется горизонтальная прокрутка из-за минимальной ширины приложения 320 px. На проверенной мобильной ширине 372 px переполнения нет.
- Выбор наград витрины сохраняется в контексте/URL, а не в серверном профиле.
