# AI Sana / TaskRank

Платформа практических задач: бизнес дополняет описание и повышает рейтинг готовности, студенческие команды выбирают задачи и отправляют предложения, бизнес вручную принимает решения.

Проект состоит из двух частей:

- [Frontend: установка, запуск и сценарий](frontend/README.md)
- [Backend: установка, запуск и тестовые данные](backend/README.md)

[Контракт API](backend/docs/api.md) и [архитектура backend](backend/docs/architecture.md) описывают интеграцию. Для локального демо сначала запустите backend с данными `python -m app.seed`, затем frontend. Backend работает на `http://127.0.0.1:8000`, frontend — на `http://localhost:5173`.
